Вот скрипт на bash для проверки свободных портов перед запуском docker-compose:

## Использование:

1. Сохраните скрипт как `check-ports.sh`
2. Сделайте исполняемым: `chmod +x check-ports.sh`
3. Запустите:
   ```bash
   ./docker-port-check.sh
   # Или
   ./dpc-short.sh
   ```
   или с указанием конкретного файла:
   ```bash
   ./docker-port-check.sh docker-compose.prod.yml
   ```

## Особенности скрипта:

- ✅ Анализирует `docker-compose.yml` и извлекает все объявленные порты
- ✅ Проверяет диапазоны портов (например, `3000-3005:3000-3005`)
- ✅ Показывает процессы, занимающие порты
- ✅ Определяет Docker контейнеры, использующие порты
- ✅ Цветной вывод для лучшей читаемости
- ✅ Поддержка разных утилит (`ss` или `netstat`)

Скрипт поможет избежать конфликтов портов при запуске docker-compose!
